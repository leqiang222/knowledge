## 分支相关

```sh
# 查看本地和远程分支
# 没有-a: 仅查看本地分支
git branch -a
# 删除本地分支
git branch -d <BranchName>
# 删除远程分支
git push origin --delete <BranchName>

# 分支检出，本地有就切换本地的，本地无远程有就拉取远程分支
# 如要检出远端 remotes/origin/develop 分支 输入命令：git checkout develop
git checkout <BranchName>
# -b的意思是一个新的分支
git checkout -b <NewBranchName> 

```

### 远程分支
```sh
# 查看远程分支信息
git remote -v
# 添加一个新的远程 Git 仓库，同时指定一个方便使用的简写。
git remote add <shortname> <url>
```

## git revert
```sh
# 撤销最近一次的提交
git revert HEAD         
# 撤销前前一次的提交
git revert HEAD^
# 撤销指定的版本，撤销也会作为一次提交进行保存。
git revert <commit-hash1> （比如：fa042ce57ebbe5bb9c8db709f719cec2c58ee7ff）
# 撤销多个提交
git revert <commit-hash1> <commit-hash2> ...
# 撤销某个范围内的提交
# 这会撤销从 （不包括）到 （包括）范围内的所有提交。
git revert <commit-hash1>^..<commit-hash2>
```
  
 
## git reset 
```sh
# 撤销HEAD 指向的分支的最新提交撤销掉，保留修改
# HEAD~1中的1是指一个提交，如果~2就是移到两个提交
git reset --soft HEAD~1
# 撤销HEAD 指向的分支的最新提交撤销掉，取消暂存的文件
git reset HEAD~1
# 撤销HEAD 指向的分支的最新提交撤销掉，并丢弃所有更改，包括暂存区和工作目录中的文件
git reset --hard HEAD~1

# 撤销指定提交
git reset <commit-hash>
```

注意：reset需要强推，将本地代码强行覆盖云端
```sh
git push origin <branch-name> --force
```

## git迁移(远程)
方法一
```sh
# 拉取老项目裸仓库，并在本地文件系统创建oldProject.git文件夹 
git clone --bare https://xx/xx/oldProject.git
# 进入代码目录 
cd oldProject.git
#向新git推送镜像 
git push --mirror https://xx/xx/newProject.git
```
方法二
```sh
# 克隆需要迁移的gitlib项目到本地（老项目的git地址）
git clone --mirror https://xx/xx/oldProject.git
# 执行下方命令修改git地址为新服务器地址 （新项目的git地址）
git remote set-url  origin https://xx/xx/newProject.git
# 推送已修改git到新地址
git push -f origin --mirror
```
