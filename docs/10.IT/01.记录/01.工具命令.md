### 文件个数
**参数说明**：
-  **ls -l**：长列表输出该目录下文件信息，每一行对应一个文件或目录，ls -lR 是递归列出所有文件，包括子目录。
- **grep "^-"**：过滤ls的输出信息，一般文件是"-"开头的，目录是"d"开头的。
- **wc -l**：统计输出信息的行数，统计结果就是输出信息的行数，一行信息对应一个文件，所以就是文件的个数。
```shell
# 统计当前目录下文件的个数（不包括目录）
ls -l | grep "^-" | wc -l
# 递归统计当前目录下文件的个数（包括子目录）
ls -lR| grep "^-" | wc -l
# 查看某目录下文件夹的个数（不包括子目录）
ls -l | grep "^d" | wc -l
# 递归查看某目录下文件夹的个数（包括子目录）
ls -lR | grep "^d" | wc -l
# 查看某目录下文件夹和文件的个数（不包括子目录）
ls -l | grep "^[-|d]" | wc -l
# 递归查看某目录下文件夹和文件的个数（包括子目录）
ls -lR | grep "^[-|d]" | wc -l
```

## Node

### n：node切换工具
注意：涉及操作的都要加sudo，因为会操作文件夹需要权限

```sh
# 首先是安装n模块：
sudo npm install -g n

# 升级node.js到最新稳定版
sudo n stable
# 升级node.js到最新版
sudo n latest
# n后面也可以跟随版本号,升级node.js到指定版本
sudo n v0.10.26 或 sudo n 0.10.26

# 切换使用版本
sudo n 7.10.0
# 删除制定版本
sudo n rm 7.10.0
# 用制定的版本执行脚本
sudo n use 7.10.0 some.js
# 查看所有已安装的node版本，并可以根据上下和回车选择要使用的版本
sudo n
# 查看 n 管理的 node 版本
sudo n [ls/list/--all]
```

### npm和pnpm常用命令

```sh
# -S 即 --save，在 dependencies 下
npm install xxx -S
# -D 即 --save-dev，在 devDependencies 下
npm install xxx -D
# -g 即 --global，作用于全局环境，安装包信息是指把模块安装到操作系统上
npm install xxx -g
```

### Yarn

```sh
# 查看版本号
yarn version

yarn init
查看全部配置项 yarn config list

删除某配置项yarn config delete <key>

# 安装包命令，该命令会根据packge.json文件安装依赖包，生成node_modules文件夹
# --force 表示强制重新下载所有包
yarn install --force
# 添加包，该命令会自动更新package.json和yarn.lock

# 删除包 该命令会自动更新package.json和yarn.lock
yarn remove <packageName> 

发布包yarn publish

查看缓存yarn cache

运行脚本**yarn run** 该命令执行在 package.json 中 scripts 属性下定义的脚本。

yarn build 该命令将源码编译成dist目录下发行文件。
```
