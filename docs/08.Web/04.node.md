## Node的一些知识

#### 名词

- **nodejs**：是一个能够在服务器端运行的JavaScript的开放源代码，跨平台JavaScript运行环境。
- **npm**：nodejs 包管理工具。
  - npm 管理 nodejs 中的第三方插件。他的作用与iOS中的cocoapods及Java中的maven相同，都是对第三方依赖进行管理的。

- **nvm**：全称“**node.js version management**”，是一个nodejs的版本管理工具，用于解决node各种版本存在的不兼容现象，它是可以在同一台机器上安装和切换不同版本的node的工具。
