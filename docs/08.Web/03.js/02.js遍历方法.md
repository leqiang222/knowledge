数组数据

```js
const studenArray = [
    {
        name: '张三',
        age: 18
    },
    {
        name: '李四',
        age: 18
    },
    {
        name: '王五',
        age: 17
    }
];
```



## forEach

```js
/// 有返回结果，返回值为undefined，本质上等同于 for 循环
studenArray.forEach((item, index, arr) => {
    console.log(index);
    console.log(item);
    console.log(arr);
});
```

## map

```js
/// 会返回一个新数组，新数组的元素为原始数组元素调用函数处理的后return返回的值
/// 下面代码 result = [ '张三', '李四', '王五' ]
const result = studenArray.map((item, index, arr) => {
    return item.name;
});
```

## filter

```js
/**
 * 遍历数组并返回一个新的数组（即过滤数组并返回新数组，不会改变原数组）
 * 直接return布尔值，为true则元素值放入数组中，为false的就被过滤掉
 * 下面代码 result = [ { name: '王五', age: 17 } ]
 */
const result = studenArray.filter((item, index, arr) => {
    if (item.age <= 17) {
        return true;
    }
    return false;
});
```

## reduce

```js
// 初始值
let initValue = 0;
// 这里的 result 是数组内的age属性相加；previous表示是前上次的result
const result = studenArray.reduce((previous, current, index, arr) => {
    return previous + current.age;
}, initValue);
```

## some和every

- some: 数组内的元素是否至少有一个满足条件
- evety: 数组内的元素是否都满足条件

上面两个函数的返回都是true或false
