## 组成

-  `ECMAScript`（前身为欧洲计算机制造商协会) ，JavaScript的语法规范，如：语法、类型、语句、关键字、保留字、操作符、对象；提供核心语言功能 
-  `DOM`（文档对象模型 Document Object Model)，JavaScript操作网页上元素的API
    - DOM把整浏览器页面映射为一个多层节点结构，页面中每个组成部分都是某种类型的节点，这些节点又包含了不同类型的数据
-  `BOM`（浏览器对象模型 Browser Object Model)，JavaScript操作浏览器部分功能的API

## 数据类型

###   简单数据类型（值类型） 

**String 字符串**

**Number 数字**

- NaN 非数值（Not a Number的简写）
	- NaN 与任何值都不相等，包括 NaN 本身 

 **Boolean 布尔**   
 -  true、除0数字、“something”、Object(任何对象)为true
 - false、0 、“”、undefined 、null为false

 **Undefined  未定义** 	  
 - Undefined和任何数值计算为NaN;   
 -  `undefined`使用var声明变量但没有初始化，区分空对象指针与尚未定义的变量，对未初始化的变量以及未声明的变量使用，typeof运算符均会返回undefined

 **null 空**
- 逻辑上`null`表示一个空对象的指针，使用typeof检测的时候会返回object；（object原型的终点也是null）

**null与undefined**相似与不同
- null == undefined的结果(true)， null ===undefined的结果(false)
- 10 + null结果为：10；10 + undefined结果为：NaN
-  任何值和null运算，null可看做0运算

## 解构

### 数组解构

基本：
```js 
let [a, b, c] = [1, 2, 3];  
// a = 1  
// b = 2  
// c = 3
```

可忽略：
```js
let [a, , b] = [1, 2, 3];
// a = 1
// b = 3
```

不完全解构和默认值
```js
let [a = 1, b] = []; // a = 1, b = undefined
```

剩余运算符
```js
let [a, ...b] = [1, 2, 3];  
// a = 1  
// b = [2, 3]
```

作用于函数参数：
```js
function f([first, second]: [number, number]) { 
	console.log(first); 
	console.log(second); 
} 
f(input);
```


### 对象解构

基本使用
```js
// 通过 `o.a` and `o.b` 创建了 `a` 和 `b`
let o = { a: "foo", b: 12, c: "bar" }; 
let { a, b } = o;
```

使用`...`剩余运算符：
```js
let {a, b, ...rest} = {a: 10, b: 20, c: 30, d: 40};  
// a = 10  
// b = 20  
// rest = {c: 30, d: 40}
```

属性重命名
```js
// 给对象o的ab属性分别重命名为newName1和newName2
let { a: newName1, b: newName2 } = o;
```

默认值，可以让你在属性为 undefined 时使用缺省值：
```js
let {a = 10, b = 5} = {a: 3};  
// a = 3; b = 5;  
let {a: aa = 10, b: bb = 5} = {a: 3};  
// aa = 3; bb = 5;
```

### 函数声明

type C = { a: string, b?: number }

	// ...

function f({ a="", b=0 } = {}) { 
	// ...

### 展开
展开操作符正与解构相反。 它允许你将一个数组展开为另一个数组，或将一个对象展开为另一个对象

```js
// 展开数组
let first = [1, 2]; 
let second = [3, 4]; 
let bothPlus = [0, ...first, ...second, 5];

// 展开对象
// food 会覆盖 defaults.food
let defaults = { food: "spicy", price: "$$", ambiance: "noisy" }; 
let search = { ...defaults, food: "rich" };
```
