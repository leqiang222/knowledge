
## 类型约束

### 类型推断（不建议使用） 
 
```js
// myName 被推断为字符串类型
let myName = 'zs'; 
// 报错：Type 'number' is not assignable to type 'string'
myName = 18;
```

### 类型注解（建议使用）

```js
let myName: string;
// 报错，Type 'number' is not assignable to type 'string'
myName = 18;
```

### 类型断言

```js
let numArr = [1, 2, 3];
// 报错：'result' is possibly 'undefined'.
const result = numArr.find((item) => item > 2); 
// ts比较严谨，若 result 为未定义的时候，则不能与 5 相乘，所以报错（在js中可以）。所以加上 as number 来约束 result 的类型
const result = numArr.find((item) => item > 2) as number;
result * 5;
```

## 类型

### 基础类型和联合类型

```js
let v1: string = "abc";
let v2: number = 10;
let v3: boolean = true;
// null类型只能赋值`null`
let nu: null = null;
// undefined类型只能赋值`undefined`
let un: undefined = undefined;
// void类型 只能为它赋予`undefined`和`null`
let unusable: void = undefined;
// 联合类型：v4 只能被分配 string 和 null 类型
let v4: string | null = null;
// 也可以做具体值的限制，这里的 v5 只能是 1 或 2 或 3
let v5: 1 | 2 | 3 = 2;
```

有时候，我们会想要为那些在编程阶段还不清楚类型的变量指定一个类型。 这些值可能来自于动态的内容，比如来自用户输入或第三方代码库。 这种情况下，我们不希望类型检查器对这些值进行检查而是直接让它们通过编译阶段的检查。 那么我们可以使用 `any`类型来标记这些变量： 

```js
let notSure: any = 4; 
notSure = "maybe a string instead"; 
notSure = false;

// 当你只知道一部分数据的类型时，`any`类型也是有用的。 比如，你有一个数组，它包含了不同的类型的数据：
let list: any[] = [1, true, "free"];
list[1] = 100;
```

`object`表示非原始类型，也就是除`number`，`string`，`boolean`，`symbol`，`null`或`undefined`之外的类型。

### 函数

``` js
// a 和 b 规定了约束了参数的类型
// ():string 约束了返回值的类型。可以为 :void 表示函数无返回值
function MyFunc1(a: number, b: string): string {
 return a + b;
}

​// b 和 c 都为可选项
// b 不填则默认为 10，c 不填默认没有
// ...rest 为剩余参数，且剩余值为一个数组结构，则可对其进行约束，为...rest: number[]
// 注意，必选参数在左，可选参数在右，否则报错
function MyFunc2(a: boolean, b = 10, c?: string, ...rest: number[]): boolean {
  return a;
} 
// 使用，后面的 1, 2, 3, 4, 5 会包装成一个数组
const f: boolean = MyFunc2(true, 20, "zx", 1, 2, 3, 4, 5); 
```

### 类型别名

```js
// 若很多参数都需要定义约束类型
let a: string | number = 10;
let b: string | number = 20;
let c: string | number = 30;
​
// 则使用类型别名
type MyType = string | number;

```

### 泛型
 
功能：若一个函数是比较通用的函数，如下面的函数，想让他处理一组字符串、布尔类型、数值类型，则可以使用泛型

```js
// 对函数定义泛型，这里的 T 你可以理解为变量名
function myFunc<T>(a: T, b: T, ...r: T[]): T[] {
 return [a, b, ...r];
}
​  
// 下面的 myFunc<number> 中 number 表示参数值可以传 number类型
// 也可以 const arr = myFunc(1, 2, 3, 12, 3); 因为 ts 支持类型推断，当你第一个参数写 number 时，则后面的参数都需要是 number
const arr: number[] = myFunc<number>(1, 2, 3, 12, 3);

// 输出 [1, 2, 3, 12, 3]
console.log(arr);
```

## 接口

### 可选属性

```js
interface Student {  
	// ? 表示可选属性
	address?: string;
}
```

### 只读属性

```js
interface Student {   
	// readonly 表示只读属性，对象构建完成后 id 的值就再也不能被改变
	readonly id: number;  
}

let s: Student  = { id: 10 };
s.x = 5; // error!
```

### `ReadonlyArray<T>`类型

它与`Array<T>`相似，只是把所有可变方法去掉了，因此可以确保数组创建后再也不能被修改：
```js
let a: number[] = [1, 2, 3, 4]; 
let ro: ReadonlyArray<number> = a; 

ro[0] = 12; // error!
ro.push(5); // error! 
ro.length = 100; // error! 
a = ro; // error!
// 下面 a = ro 报错可以看出，ReadonlyArray 赋值到一个普通数组。但是你可以用类型断言重写
a = ro as number[]; // ✅
```

### 额外的属性检查

 ```js
interface Student {   
	name?: string
	address?: string;
}

function createCard(s: Student) { 
	// ...
}
// 因为属性检查，这里会报错：error: 'haha' not expected in type 'Student'
createCard({ name: 'zs', haha: 'o'});

// 绕开上面上错1（不推荐）：使用类型断言
createCard({ name: 'zs', haha: 'o'} as Student);
// 绕开上面上错2（推荐）：添加一个字符串索引签名
interface Student {   
	name?: string
	address?: string; 
	[propName: string]: any; // 字符串索引签名
}

```

### 继承接口

简单示例
```js 
interface Shape { 
	color: string;
}
interface Square extends Shape {
	sideLength: number; 
}
```

一个接口可以继承多个接口，创建出多个接口的合成接口。
```js
interface Shape {  
   color: string;  
}   
interface PenStroke {  
   penWidth: number;  
}  
  
interface Square extends Shape, PenStroke {  
   sideLength: number;  
}
```

## 枚举

数字枚举
```js
// `Up`使用初始化为 `1`。 其余的成员会从 `1`开始自动增长
// Direction.Up = 1，以此类推 
enum Direction {  
   Up = 1,  
   Down,  
   Left,  
   Right  
}
```

字符串枚举
```js
enum Direction {  
   Up = "UP",  
   Down = "DOWN",  
   Left = "LEFT",  
   Right = "RIGHT",  
}
```

计算的和常量成员
```js
// E.X = 0
enum E { 
	X 
} 
```

常量枚举
```js
// 常量枚举只能使用常量枚举表达式
const enum Enum {  
   A = 1,  
   B = 2
}
```

外部枚举
```js
declare enum Enum {  
   A = 1,  
   B,  
   C = 2  
}
```
