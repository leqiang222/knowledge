```js
interface Student {
	name?: string;
	age?: number;
}
```

- 给变量ss指定对象类型
```js
const ss = ref<Student>();
```

- 给computed返回指定类型
```ts
const currentState = computed<string>(() => { 
	return '0';
});

```

- 结构的对象可能是undefine的警告处理
```js
const ss = ref<Student>();
const { name, age } = ss.value ?? ({} as Student);
```
