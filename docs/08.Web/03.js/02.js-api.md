## 字符串

是否包含子字符串
```js 
let a = 'apple,banana,orange';

// includes函数  
if (a.includes('orange')) {  
   console.log('字符串包含 orange');  
} else {  
   console.log('字符串不包含 orange');  
}

// indexOf函数
if (a.indexOf('orange') !== -1) {  
   console.log('字符串包含 orange');  
} else {  
   console.log('字符串不包含 orange');  
}

// search函数
// search函数和indexOf函数相似，但是search函数可以使用正则表达式
if (a.search('orange') !== -1) {  
   console.log('字符串包含 orange');  
} else {  
   console.log('字符串不包含 orange');  
}
```

开头和结尾
```js
let a = 'apple,banana,orange';

// 下面两个函数返回boolean，如果需要知道子串的位置，还是得用 indexOf 和 lastIndexOf
string.startsWith("apple"); // true 
string.endsWith("apple"); // false

```

## 数值

转成 Number 类型
```js
// 字符串转换为数字
// 它会尝试解析字符串中的数字部分。如果字符串中包含哪怕一个非数字字符，则返回 NaN
let num = Number('18.2'); // num = 18.2
let num = Number('18a'); // num = NaN
```

转成 Int 类型
```js
// 与全局的 parseInt() 函数是同一个函数 
Number.parseInt = parseInt; // true

// 字符串转换为整数, 整数向下取整
// 字符串中包含非数字字符，截取前面的数字字符解析，如果第一个字符为非数字，，则返回 NaN
let num = parseInt('18.8'); // num = 18
let num = parseInt('18a'); // num = 18
let num = parseInt('a18'); // num = NaN
```

转成 Float 类型
```js
// 字符串转换为浮点型 
let num = parseFloat('18.0'); // 18
let num = parseFloat('18.5'); // 18.5
let num = parseFloat('a18') // NaN
```

## 对象

`Object.assign(target, source_1, ···)` 源对象的所有可枚举属性复制到目标对象中
```js
let target = {a: 1};  
let object2 = {b: 2};  
let object3 = {c: 3};  

// 第一个参数是目标对象，后面的参数是源对象  
// 最后 target = {a: 1, b: 2, c: 3}
let c = Object.assign(target, object2, object3);    
c === target; // true
```

```js
// 数组的处理，会将数组处理成对象，所以先将 [2,3] 转为 {0:2,1:3} ，然后再进行属性复制，所以源对象的 0 号属性覆盖了目标对象的 0。
Object.assign([2,3], [5]); // [5,3]
```

因为 null 和 undefined 不能转化为对象，所以会报错:
```js
// TypeError: Cannot convert undefined or null to object
Object.assign(null);         
Object.assign(undefined);  

// 当参数不止一个时，且 null 和 undefined 不放第一个，即不为目标对象时，会跳过 null 和 undefined ，不报错  
Object.assign(1, undefined);  // Number {1}  
Object.assign({a: 1}, null);  // {a: 1}   
Object.assign(undefined, {a: 1});  // TypeError: Cannot convert undefined or null to object
```

assign 的属性拷贝是浅拷贝: 也就是说 targetObj 里的值改变，sourceObj有这个值也会跟着改变
```js
let targetObj = {c: 3};  
let sourceObj = { a: { b: 1}};  
Object.assign(targetObj, sourceObj);  
targetObj.a.b = 2;  
sourceObj.a.b;  // 2
```

## 数组遍历

示例数据：

```js
const studentArray = [
    {
        name: '张三',
        age: 18
    },
    {
        name: '李四',
        age: 18
    },
    {
        name: '王五',
        age: 17
    }
];
```

### forEach

- 有返回结果，返回值为undefined，本质上等同于 for 循环

```js
studentArray.forEach((item, index, arr) => {
    console.log(index);
    console.log(item);
    console.log(arr);
});
```

### map

- 会返回一个新数组，新数组的元素为原始数组元素调用函数处理的后return返回的值

```js
// 下面代码 result = [ '张三', '李四', '王五' ]
const result = studentArray.map((item, index, arr) => {
    return item.name;
});
```

### filter

- 遍历数组并返回一个新的数组（即过滤数组并返回新数组，不会改变原数组）
- 直接return布尔值，为true则元素值放入数组中，为false的就被过滤掉

```js
// 下面代码 result = [ { name: '王五', age: 17 } ]
const result = studentArray.filter((item, index, arr) => {
    if (item.age <= 17) {
        return true;
    }
    return false;
});
```

### reduce

```js
// 初始值
let initValue = 0;
// 这里的 result 是数组内的age属性相加；previous表示是前上次的result
const result = studentArray.reduce((previous, current, index, arr) => {
    return previous + current.age;
}, initValue);
```

### some和every

- some: 数组内的元素是否至少有一个满足条件
- every: 数组内的元素是否都满足条件

上面两个函数的返回都是true或false

### find

查找数组中符合条件的元素，若有多个符合条件的元素，则返回第一个元素； 
```js
// 下面代码 result = { name: '张三', age: 18 }
const result = studenArray.find((item) => { 
	return item.age >= 18;
});

// 下面代码 result = undefined
const result = studenArray.find((item) => { 
	return item.age >= 19;
});
```

### findIndex

返回传入一个测试条件（函数）符合条件的数组第一个元素位置	 
```js
// 下面代码 result = 0，表示索引 index = 0 的就符合
const result = studentArray.findIndex((item) => {
    return item.age >= 18;
});

// 下面代码 result = -1，表示没有符合的
const result = studentArray.findIndex((item) => {
    return item.age <= 16;
});
```

## ES6模块

### 基本用法

```js
/*-----export [test.js]-----*/
let myName = "zs";
let myFunc = function(){  
   return "My name is" + myName
} 
export { myName, myFunc }

/*-----import [xxx.js]-----*/
import { myName, myFunc } from "./test.js";
```

### as 的用法

export 命令导出的接口名称，须和模块内部的变量有一一对应关系。 
import 导入的变量名，须和导出的接口名称相同，即顺序可以不一致。
```js
/*-----export [test.js]-----*/  
let myName = "Tom";  
export { myName as exportName }  
  
/*-----import [xxx.js]-----*/  
import { exportName } from "./test.js";
console.log(exportName); // Tom
```

```js
/*-----export [test1.js]-----*/  
let myName = "Tom";  
export { myName }  
/*-----export [test2.js]-----*/  
let myName = "Jerry";  
export { myName }  

/*-----import [xxx.js]-----*/  
import { myName as name1 } from "./test1.js";  
import { myName as name2 } from "./test2.js";  
console.log(name1); // Tom  
console.log(name2); // Jerry
```

### export default 命令

- 在一个文件或模块中，export、import 可以有多个，export default 仅有一个。
- export default 中的 default 是对应的导出接口变量。
- 通过 export 方式导出，在导入时要加{ }，export default 则不需要。
- export default 向外暴露的成员，可以使用任意变量来接收。
```js
var a = "My name is Tom!";  
export default a; // 仅有一个  
export default var c = "error";  

import b from "./xxx.js"; // 不需要加{}， 使用任意变量接收
```

## 正则
#### 正则的组成

> 每一个正则表达式都是由元字符和修饰符组成的

什么是[元字符]：在//之间具有意义的一些字符

###### 具有特殊意义的元字符

- `:`转义字符,转译后面字符所代表的含义
- `^`: 以某一个元字符开始
- `$`: 以某一个元字符结尾
- ` \n`: 匹配一个换行符
- `.`: 除了\n以外的任意一个字符
- ```js
  var reg = /^0.2$/;//->以0开头,以2结尾,中间可以是除了\n的任意一个字符
  console.log(reg.test("0.2"));//->true 
  console.log(reg.test("0-2"));//->true
  console.log(reg.test("0s-2"));//->false
  //
  reg = /^0\.2$/;//->以0开头,以2结尾,中间是.的字符串；
  console.log(reg.test("0.2"));//->true
  console.log(reg.test("0-2"));//->false
  ```
```js
- `()`: 功能一:分组 ->把一个大正则本身划分成几个小的正则
- ```
var reg1 = /^\d+zhu\d+$/;
var reg2 = /^(\d+)zhu(\d+)$/;
//匹配
console.log(reg1.test("2zhu3"));//true
console.log(reg2.test("2zhu4"));//true
//捕获
console.log(reg1.exec("2zhu3"));//["2zhu3", index: 0, input: "2zhu3"]
console.log(reg2.exec("2zhu4"));//["2zhu4", "2", "4", index: 0, input: "2zhu4"]
```
- `x|y`: x或者y中的一个
- `^x|yz$`: x开头、yz结尾、x开头并且yz结尾、三种都可以
- `[xyz]`: x或者y或者z中的一个
- `[^xyz]`: 除了三个以外的任何一个字符
- `[a-z]`: a-z之间的任何一个字符
- `[^a-z]`: 除了a-z之间的任何一个字符
- `\d`: 一个0-9之间的数字  `\D`: 除了0-9之间的数字以外的任何字符
- `\b`: 匹配一个边界符
- `\w`: 数字、字母、下划线中的任意一个字符，等于`[0-9a-zA-Z_]`
- `\s`: 匹配一个空白字符 空格、一个制表符、换页符...

######代表出现次数的量词元字符
- `*`: 出现零到多次
- `+`: 出现一到多次
- `?`: 出现零次或者一次
- `{n}`: 出现n次
- `{n,}`: 出现n到多次
- `{n,m}`: 出现n到m次
- ```js
  var reg = /^\d+$/;

  console.log(reg.test("13856487589"));//true
  console.log(reg.test("12114567895"));//false
  ```

###正则实践
- 有效数字的正则(可以是 正数、负数、零、小数 )
```
1)、"."可以出现也可以不出现,但是一旦出现,后面必须跟着一位或者多位数字
2)、最开始可以有+/- 也可以没有
3)、整数部分,一位数可以是0-9之间的一个,多位数不能以0开头
var reg = /^[+-]?(\d|([1-9]\d+))(\.\d+)?$/;//.是一个元字符，所以需要转义；
```
