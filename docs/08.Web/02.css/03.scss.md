## 伪类

### 伪类第几个

```scss
.card {
  color: black;
  /* card类第一个 */
  &:first-child {
    color: red;
  } 
  /* card类第2个 */
  &:nth-child(2) {
    color: red;
  } 
  /* card类最后一个 */
  &:last-child {
    color: red;
  }
  /* card类倒数第2个 */
  &:nth-last-child(2) {
    color: red;
  }
}
 
/** 表示第一个aaa类是红色 */
 .aaa:first-of-type {
  color: red;
} 

// 应用样式到第一个 <p> 元素
p:first-of-type { 
  color: red;
}

/** 表示不是第一个aaa类都是红色 */
.aaa:not(:first-of-type) {
  color: red;
}
.aaa:last-of-type {
	color: red;
}
```



### 直接子节点

```css
.card {
  height: 100vh; 
  /* 给直接子节点设置属性 */
  > * { 
    color: red; 
  }
  /* 后代所有节点 */
  * {
    color: blue; 
  }
}

```
