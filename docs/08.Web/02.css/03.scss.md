## 伪类

### 伪类第几个

```css
.card {
  color: black;
  /* card类第一个 */
  &:first-child {
    color: red;
  } 
  /* card类第2个 */
  &:nth-child(2) {
    color: red;
  } 
  /* card类最后一个 */
  &:last-child {
    color: red;
  }
  /* card类倒数第2个 */
  &:nth-last-child(2) {
    color: red;
  }
}
```

### 直接子节点

```css
.card {
  height: 100vh; 
  /* 给直接子节点设置属性 */
  > * { 
    color: red; 
  }
  /* 后代所有节点 */
  * {
    color: blue; 
  }
}

```
