## 容器属性

### flex-wrap
flex-wrap 属性主要处理在一条轴线上排不下项目元素如何换行的问题：

```scss
// （默认值），不换行
flex-wrap: nowrap;
// 换行
flex-wrap: wrap;
// 换行，但第一行在下方，颠倒了顺序
flex-wrap: wrap-reverse;
```

### flex-flow
flex-flow属性是flex-direction属性和flex-wrap属性的简写形式

```scss
// 默认值
flex-flow: row nowrap;
```

### justify-content

> justify-content: flex-start | flex-end | center | space-between | space-around;

justify-content定义了 Flex 项目在主轴上的对齐方式
```scss
// 左对齐
justify-content: flex-start;
// 右对齐
justify-content: flex-end;
// 水平居中
justify-content: center;
// 项目之间的间隔都相等，容器两边间隔0
justify-content: space-between;
// 项目之间的间隔距离，容器两边间隔为项目间间隔一半
justify-content: space-around;
```

### align-items

> align-items: flex-start | flex-end | center | baseline | stretch;

align-items定义了 Flex 项目在交叉轴上如何对齐
```scss
// (默认值)stretch是'延伸'的意思，如果项目未设置高度或设为height: auto，将占满整个容器的高度。
align-items: stretch;
//  项目的第一行文字的基线对齐，即项目里的内容是对齐一条线的 
align-items: baseline;
// 交叉轴的起点对齐 
align-items: flex-start;
// 交叉轴的终点对齐 
align-items: flex-end;
// 交叉轴的中点对齐（垂直居中） 
align-items: center;
```
### align-content属性

> align-content: flex-start | flex-end | center | space-between | space-around | stretch;

align-content定义了存在多根主轴线时，Flex 项目在交叉轴上如何对齐，如果项目只有一根主轴线，该属性不起作用

```scss
// (默认值)，主轴线平分 Flex 容器交叉轴方向上的空间
// 容器和行之间，间距一样
align-content: stretch;
// 与交叉轴的起点对齐 
// 从顶部一个个排下来
align-content: flex-start;
// 与交叉轴的终点对齐
// 从底部一个个排上去
align-content: flex-end;
// 与交叉轴的中点对齐 
// 在中间一个个排下来
align-content: center;
// 与交叉轴两端对齐，轴线之间的间隔平均分布 
// 容器没间距，行间距一样
align-content: space-between;
// 根轴线两侧的间隔都相等，所以轴线之间的间隔比轴线与边框的间隔大一倍
// 容器一般间距，行间距一样
align-content: space-around;
```

## 项目属性

### order
order属性定义项目的排列顺序。数值越小，排列越靠前，默认为0。

### flex-grow
flex-grow定义了 Flex 项目在主轴方向上的放大比例，默认为 0，即如果存在剩余空间，该项目也不放大
- 如果都不设置 flex-grow，则不会分掉剩余空间，剩余空间依旧存在
- 如果有的 Flex 项目有 flex-grow 属性，有的项目没有 flex-grow 属性，但有width 这样的属性，有 flex-grow 属性的项目将等分剩余空间
- 如果所有项目的 flex-grow 属性都为 1，则它们将等分剩余空间（如果有的话）
- 如果一个项目的 flex-grow 属性为 2，其他项目都为1，则前者占据的剩余空间将比其他项多一倍
- 
### flex-shrink
flex-shrink定义了 Flex 项目在主轴方向上的缩小比例，默认为 1，即如果空间不足，该项目将缩小
- 如果所有项目的 flex-shrink 属性都不为 0，当空间不足时，都将等比例缩小
- 如果一个项目的 flex-shrink 属性为 0，其他项目都为1，则空间不足时，前者不缩小

### flex-basis
**flex-basis定义了在分配多余空间之前，Flex 项目占据的主轴大小（main size）**
浏览器根据这个属性，计算主轴是否有多余空间，它的默认值为 auto，即项目的本来大小

### align-self

> align-self: auto（默认值） | flex-start | flex-end | center | stretch | baseline;

**允许单个项目有与其他项目不一样的对齐方式，可覆盖 align-items 属性**
