# 夜景拍摄 
####拍摄条件

最好是在太阳下山前后10-20分钟，因为这时候天空还是蓝的或是落日余晖，这个时候天空的冷色调和灯光的暖色调想结合会更有层次感

####相机设置

* **防抖：**关闭防抖
* **模式：**新手建议用光圈优先，
* **ISO：**为了获取纯净细腻的画面， 建议将ISO值设置为100（同时也是为了较小曝光时间）
* **光圈：**光圈最好设置为8-11之间，太小会产生衍射现象，严重影响画质
* **白平衡：**自动白平衡下，画面的色彩会显得灰雾，所以建议使用钨丝灯白平衡（整个画面偏蓝色冷色调），或者白色荧光灯（会偏洋红色）
* **色温值：**色温值越低，越偏冷色调，建议设置在3000-5000之间
