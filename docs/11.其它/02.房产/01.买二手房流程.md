# 二手房买卖流程

整体上讲，买卖双方需要出场的：合同签约，网签，公积金面签，商贷申请（面签），过户，一共五次。另外我作为买方，因为自己申报按揭，然后除了交税外，没有再额外交过一分钱。

建议关注三个微信公众号：

- 广州住房公积金管理中心：可以线上申请贷款，预约面签，了解进度等
- 广州住房职业融资担保有限公司：主要是预约抵押
- 广州不动产登记：主要是查册，及时了解自己名下房产信息，也可以将查询信息下载下来提交给到银行，免去房管局打印查册

时间表:

```js
1、签买卖双方合同
2、网签：可以跟1同步，当天完成
3、赎楼：提交赎楼申请，招行22个工作日完成审核，扣款一个工作日，涂销7个工作日，建议预留2个月时间。如果想快，就赎楼跟贷款同家银行，内部转换一个工作日可完成
4、申请公积金贷：微信广州住房公积金管理中心自助申请，3个工作日审核。现场申请7-9个工作日审核。审核通过预约面签1个工作日。面签通过，首付托管1个工作日；资料返回银行盖章3个工作日；全部完成后会有短信通知预约抵押时间，盖章完成-短信通知，1-3个工作日。
5、申请商贷：资料审核3个工作日；房产评估及出报告1-3个工作日。可与公积金同步，或在公积金通知面签之后开始申请
6、税审：1-3个工作日，可在商贷或者公积金贷同贷书出来后提前申请
7、预约过户及抵押：只能预约2个工作日后
8、过户、抵押、交税、水电煤气过户：1个工作日
9、出新证：7天
10、放款：出新证后3个工作日，公积金放款首付托管资金；正常一个星期左右放公积金尾款和商贷尾款。
```

## 二、双方签订意向合同

#### 注意事项

- 注意违约金
- 注意过户的家具、家电
- 存在一定的变数，如卖家房子存在法院查封等因素的话，需要写好和平解约

#### 准备材料

- 身份证
- 查册资料（任意一家房管局24小时自助打印，可同时查家里所有人的名下房产）
- 房产证（如果房产证抵押在银行，需要申请加盖银行章的复印件）

## 三、网签

签了意向合同后理论上就可以网签了。一般大的中介都可以直接在分店或者是总部进行网签，周末可以安排网签。

比如在裕丰网签时，我们要在手机上操作，并人脸识别。

#### 注意事项

- 记得让中介多打印一两份网签材料，自己至少带走一份，后续可能有用。

#### 准备材料

##### 卖家

- 夫妻双方本人携带夫妻双方身份证原件
- 双方户口本原件
- 结婚证原件
- 房产证原件（或者复印件加盖银行业务章）

##### 买家

- 夫妻双方本人携带夫妻双方身份证原件
- 双方户口本原件
- 结婚证原件

## 四、确定按揭/赎楼公司

#### 流程

##### 卖家

- 卖房找第三方赎楼，赎楼有两个方案，一个是垫资过桥，1.8%+公证费（从垫资到收款1个月内，超过1个月要再加钱，另外收款是从首付款里扣减，好处是不限制按揭银行），二是跨行赎楼（类似于早期的转按揭），卖家最后谈下的费用是1.1%+银行利息（一个月0.6-0.7%）+公证费（700元，实际上就是找个名目收钱，没有任何用处），费用是包三个月，即从垫资到收款不超过3个月，费用都是1.1%，利息按实际时间收取。有看到别人说是可以0.8%+0.4%的利息，但是我们咨询了几家，都没有做到这么低。另外买家一起谈好按揭费2000元，包房产评估。我后来买房时本来也想找他们按揭，南沙的按揭费他们报价要3000元。 

## 五、提交按揭申请

#### 注意事项

- 如果是正常的按揭，可以让银行代为一并提交公积金申请。那样的话就简单许多。
- 公积金贷款最便捷的方式，便是自己在微信上关注“广州住房公积金管理中心”，自助提交申请。按照流程规定，从提交资料到审核通过最多3个工作日。比柜台申请高效多了（柜台申请正常7-9个工作日）。前提是资料必须填对。我个人资料有三处填错，其中一处是房产证漏拍了楼层分布图，这个审核时被退回补充提交就可以。一处是共有产权人页面无须填写自己资料，只需要填写对方资料（如夫妻），这个并非原则性问题。最主要的一个错误就是放款银行一定要问清，一般是**银行广州支行，我错填成了开户支行，最后面签时被工作人员指出，只能作废，重新走线下流程申请。那工作人员不错，给加快了进度，最终4个工作日重新接到面签通知。面签通过后，需要返回银行盖章，再由银行工作人员拿回公积金担保公司处，正常是三个工作日。最好催一下你的银行客户经理。我的是刚好商贷同期下来，客户经理连同商贷同贷书和公积金同贷书一起拿给公积金，在过户的时候公积金的工作人员一起带到房管局。
- 自助申请需要的资料，按照流程来准备好就可以。
- 提交申请可以选择就近的公积金办公地点，不需要是房产所在地。面签时，如果买卖双方都是共有产权，需要一起到场；如果只是一方产权，那么一方到场就可以。公积金完成面签之后，一般一个工作日就会完成首付托管资金扣款。商贷倒是需要夫妻双方一起到场，有个签字需要双方。
- 公积金是不需要线下房产评估，有个线上自动评估，不过要求每月还款不得超过你交公积金的工资基数的50%，另外一手房贷款期限不超过30年，二手房不超过20年，最高金额不超过60万，可以夫妻两人一起申请公积金贷款。
- 商贷要查流水和负债率，如果有大额贷款的话，银行会要求你先还清。`如果个人的流水、征信或者是负债率不合格，就最好找中介公司替你搞定，前提是支付一定的手续费`。
- 纯商贷的话如果找一些外资银行，利率更低，之前我收到的最低报价是汇丰还是花旗4.6%，不过外资银行就不接受组合贷。

## 六、税审

过户之前需要先进行税审，我的是中介代为办理的，具体流程不清。只知道几个细节：

- 税审跟按揭流程无关，不需要等到同贷书下来后才开始申请。正常审核时间是1-3个工作日。
- 税审通过后，需要在15个工作日内完成入户与交税，否则将产生每天万分之五的违约金，所以也不宜太早。组合贷可以拿到其中一个同贷书的时候再开始提交税审

## 七、预约过户、抵押

公积金处收到银行提交的盖章资料之后，正常1-3个工作日会发出一条通知，内容大意是已完成面签，请预约抵押登记的时间。
这个最好自己关注“广州住房置业融资担保有限公司”微信公众号，绑定个人资料，可以及时查询进度及办理流程。
收到短信，并确认商贷同贷书已下来，就可以预约过户和抵押，广州市规定只能申请两个工作日之后的抵押申请。另外公积金的办公时间是有限制的，天河的是周一至周四上午9:30-12:00，南沙则是周一、二、三、五上午9:30-12:00，最好自己确认下房产所属区域的办公时间。
`抵押是由买家申请，过户则由卖家申请`。需提醒的是，过户和抵押的可预约时间未必一致，最好先确认好可预约时间，再一起选择， 如果无法协调的或者想赶时间的，就去房管局现场取号。只是现场取号给排的时间会晚一点。我们当时申请时，抵押先选了周四，过户只有周五时间，后来就没有预约过户时间，周四去了现场取号，刚好有人取消预约，工作人员就把号给了我们。

## 八、过户、入押、交税、赎楼涂销、水电煤气过户

这五个现在是可以一站式办理。赞一下南沙房管局，过户和交税是一个窗口，同步办理，非常方便。只要资料齐全的话，基本上十多分钟就可以办理好。
水电过户可以现场办理，煤气过户可以现场预约入户检查。这些可以凭借过户回执的拍照就可以办理，卖家可以不用到场。
查册可以当天在房管局过户时现场查询及打印，不需要额外跑一趟。另外办理过户之前，需要提前联系公积金的工作人员，让他将公积金资料和商贷资料给你；办理过户之后，需要将回执给回他。同时签订一份委托书，到时新房产证会由公积金和银行那边代领。
过户完之后其实就没什么事了，尤其是招行这种要将房产证收走的。。。
新房产证正常是一周内出来，一般3个工作日。新证出来后3天内公积金会将首付托管的部分放款。最近银行比较宽松，放款超快，我卖房的时候是首付放款后，第二天就收到商贷尾款，第三天收到公积金贷款尾款。

#### 准备材料

##### 首套买家

- 身份证(夫妻双方）原件及复印件正反面 2份

- 结婚证（离婚证、离婚协议、法院判决书）原件及复印件 2份

- 户口本（户主页+夫妻双方+未成年子女）原件及复印件  2份   复印格式（户主页+个人页），复印同一张A4纸      

- 有效期内的以家庭为单位的查册纸（夫妻双方+未成年子女包括曾用名）(查册有效期为3天)
- 非广州市户口提供近5年不间断社保或个税

##### 卖家

- 身份证（夫妻双方）原件及复印件正反面  2份  
- 结婚证原件及复印件   1份
- 户口本（户主页+夫妻双方）原件及复印件  1份(户主页+个人页）
- 效期内的以家庭为单位的查册纸（夫妻双方+未成年子女包括曾用名）(查册有效期为3天)
- 房产证原件及复印件1份。备注：还需复印图纸页按1：1比例复印（2张）
- 若有抵押情况下，须带齐银行出具的赎证资料
