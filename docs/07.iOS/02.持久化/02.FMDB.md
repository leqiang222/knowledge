 # FMDB

### FMDB两个主要类，FMDatabase和FMDatabaseQueue区别?

- `FMDatabase`线程不安全，多个线程同时使用一个`FMDatabase`实例，可能会造成数据混乱。`FMDatabaseQueue`类，线程安全，它内部维护了一个串行队列来保证线程安全。

```objectivec
_queue = dispatch_queue_create([[NSString stringWithFormat:@"fmdb.%@", self] UTF8String], NULL);

- (void)inDatabase:(__attribute__((noescape)) void (^)(FMDatabase *db))block {
    // ...省略部分代码
    
    dispatch_sync(_queue, ^() {
        FMDatabase *db = [self database];
        block(db);
    });
    
    // ...省略部分代码
} 
```

### FMDB数据库升级

- 第一种，查询是否缺字段

```objectivec
// 判断表格中是否有orderType字段
[self.dbQueue inDatabase:^(FMDatabase *db) {
    NSString *kOrderTypeKey = @"orderType";
    if (![db columnExists:kOrderTypeKey inTableWithName:@"->表名"]) {
        NSString *addStr = [NSString stringWithFormat:@"alter table '%@' add %@ INTEGER", @"->表名", kOrderTypeKey];
        BOOL result = [db executeUpdate:addStr];
        if (!result) {
            NSLog(@"log_db, 修改消息表结构失败");
        }
    }
}];
```

- 第二种，第三方框架`FMDBMigrationManager`

```objectivec
// DBPath是要升级的数据库的地址 
// [NSBundle mainBundle]是保存数据库升级文件的位置 根据自己放文件的位置定 升级文件是什么下面会说
FMDBMigrationManager *manager = [FMDBMigrationManager managerWithDatabaseAtPath:DBPath migrationsBundle:[NSBundle mainBundle]];

// 下面创建版本号表，这个表会保存在我们的数据库中，进行数据库版本号的记录
BOOL resultState = NO;
NSError *error = nil;
if (!manager.hasMigrationsTable) {
    resultState = [manager createMigrationsTable:&error];
}

// 	
resultState = [manager migrateDatabaseToVersion:UINT64_MAX progress:nil error:&error];
```
