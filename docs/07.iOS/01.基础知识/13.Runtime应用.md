# Runtime应用

## 获取对象的所有属性

```c
Ivar *ivarList = class_copyIvarList(self, &count);
```

应用场景：

- 字典转模型
- NSCoding解归档

#### 字典转模型

- `Ivar *ivarList = class_copyIvarList(self, &count);`函数获取对象的列表。for循环`Ivar`拿到属性名称去待转的字典取value，再通过`KVC`对对象属性赋值
- 需要考虑二级转换
  - 如果根据属性名取到的value是`字典`或者`数组`，则要再进行字典或数组转模型

```objc
/*
 * 只考虑字典嵌套字典，不考虑字典嵌套字典数组
 */
+ (instancetype)modelWithDict:(NSDictionary *)dict{
    // 1.创建对应类的对象
    id objc = [[self alloc] init];
    // count:成员属性总数
    unsigned int count = 0;
   // 获得成员属性列表和成员属性数量
    Ivar *ivarList = class_copyIvarList(self, &count);
    for (int i = 0 ; i < count; i++) {
        // 获取成员属性
        Ivar ivar = ivarList[i];
        // 获取成员名
       NSString *propertyName = [NSString stringWithUTF8String:ivar_getName(ivar)];
        // 获取key
        NSString *key = [propertyName substringFromIndex:1];
        // 获取字典的value key:属性名 value:字典的值
        id value = dict[key];
        // 获取成员属性类型
        NSString *propertyType = [NSString stringWithUTF8String:ivar_getTypeEncoding(ivar)];
        // 二级转换
        // value值是字典并且成员属性的类型不是字典,才需要转换成模型
        if ([value isKindOfClass:[NSDictionary class]] && ![propertyType containsString:@"NS"]) {
            // 进行二级转换
            // 获取二级模型类型进行字符串截取，转换为类名
            NSRange range = [propertyType rangeOfString:@"\""];
            propertyType = [propertyType substringFromIndex:range.location + range.length];
            range = [propertyType rangeOfString:@"\""];
            propertyType = [propertyType substringToIndex:range.location];
            // 获取需要转换类的类对象
           Class modelClass =  NSClassFromString(propertyType);
           // 如果类名不为空则进行二级转换
            if (modelClass) {
                // 返回二级模型赋值给value
                value =  [modelClass modelWithDict:value];
            }
        }
        if (value) {
            // KVC赋值:不能传空
            [objc setValue:value forKey:key];
        }
    }
    // 返回模型
    return objc;
}
```

#### NSCoding解档归档

- 和字典转模型类似，`Ivar *ivarList = class_copyIvarList(self, &count);`函数获取对象的列表。for循环`Ivar`拿到属性名去解归档

  ```objc
  // 归档
  id value = [aDecoder decodeObjectForKey:key];
      if (value) {
          [self setValue:value forKey:key];
       }
  }
        
  // 解档
  id value = [self valueForKeyPath:key];
  [aCoder encodeObject:value forKey:key];
  ```

## 动态添加属性

```c
objc_setAssociatedObject(self, &kTargetKey, block, OBJC_ASSOCIATION_COPY_NONATOMIC);

objc_getAssociatedObject(self, &kTargetKey);
```

应用场景：

- 分类添加属性
- Target事件转Block

#### 分类添加属性

- MJRefresh的mj_head等都是为分类添加属性

#### Target事件转Block

原理就是`UIGestureRecognizer`分类讲`block`作为属性，当调target的就是就调这个`block`即可

```objc
static const int kTargetKey; // 属性的key

@implementation UIGestureRecognizer (Extension)

- (instancetype)initWithActionBlock:(KLGestureBlock)block {
    self = [self init];
    [self addActionBlock:block];
    [self addTarget:self action:@selector(invoke:)];
    
    return self;
}

#pragma mark - Private
- (void)addActionBlock:(KLGestureBlock)block {
    if (block) {
        // @param object：给哪个对象设置属性
        // @param key：一个属性对应一个Key，将来可以通过key取出这个存储的值，key可以是任何类型：double、int 等，建议用char可以节省字节
        // @param value：给属性设置的值
        // @param policy：存储策略
        objc_setAssociatedObject(self, &kTargetKey, block, OBJC_ASSOCIATION_COPY_NONATOMIC);
    }
}

- (void)invoke:(id)sender {
    // 利用参数key 将对象object中存储的对应值取出来
    KLGestureBlock block = objc_getAssociatedObject(self, &kTargetKey);
    if (block) {
        block(sender);
    } 
}

@end
```

## 交换方法

应用场景：

- 数组越界导致的闪退，hook `- (*id)objectAtIndex:(NSUInteger)index`
- NSMutableDictionary，set的key为空导致的闪退，hook `setObject:forKey:`
- NSUserDefaults 存储时key为nil，hook
- 对字符串操作时，hook
- 比如给所有的控制器view设置一个统一背景色，父类继承方法对OC单继承略显耦合，可以交换viewDidLoad方法实现
- hook`pointInside:withEvent:`，为UIView增加出发面积
- 无埋点

```objc
+ (void)exchangeInstanceMethod1:(SEL)method1 method2:(SEL)method2
{
    method_exchangeImplementations(class_getInstanceMethod(self, method1), class_getInstanceMethod(self, method2));
}

+ (void)load
{
    [self exchangeInstanceMethod1:@selector(reloadData) method2:@selector(mj_reloadData)];
}
```

#### 为UIView增加触发面积

```objc
void Swizzle(Class c, SEL orig, SEL new) {
    Method origMethod = class_getInstanceMethod(c, orig);
    Method newMethod = class_getInstanceMethod(c, new);
    
    if (class_addMethod(c, orig, method_getImplementation(newMethod), method_getTypeEncoding(newMethod))){
        class_replaceMethod(c, new, method_getImplementation(origMethod), method_getTypeEncoding(origMethod));
        
    }else {
        method_exchangeImplementations(origMethod, newMethod);
    }
}

@implementation UIView (TouchInset)
+ (void)load {
    Swizzle(self, @selector(pointInside:withEvent:), @selector(myPointInside:withEvent:));
}

- (BOOL)myPointInside:(CGPoint)point withEvent:(UIEvent *)event {
    if (UIEdgeInsetsEqualToEdgeInsets(self.kl_touchExtendInset, UIEdgeInsetsZero) || self.hidden ||
        ([self isKindOfClass:UIControl.class] && !((UIControl *)self).enabled)) {
        return [self myPointInside:point withEvent:event]; // 开始的实现方法
    }
    
    CGRect hitFrame = UIEdgeInsetsInsetRect(self.bounds, self.kl_touchExtendInset);
    hitFrame.size.height = MAX(hitFrame.size.height, 0);
    
    return CGRectContainsPoint(hitFrame, point);
}

static char touchExtendInsetKey;
- (void)setKl_touchExtendInset:(UIEdgeInsets)kl_touchExtendInset {
    objc_setAssociatedObject(self, &touchExtendInsetKey, [NSValue valueWithUIEdgeInsets:kl_touchExtendInset], OBJC_ASSOCIATION_RETAIN);
}

- (UIEdgeInsets)kl_touchExtendInset {
    return [objc_getAssociatedObject(self, &touchExtendInsetKey) UIEdgeInsetsValue];
}

@end
```

#### 数组越界

```objc
+ (void)load
{
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        /* 数组有内容obj类型才是__NSArrayI ,NSArray在runtime中对应的是__NSArrayI */
        NSArray* obj = [[NSArray alloc] initWithObjects:@0, @1, nil];
        [obj swizzleInstanceMethod:@selector(objectAtIndex:) withMethod:@selector(hookObjectAtIndex:)];
        [obj release]; 
    });
}

- (id) hookObjectAtIndex:(NSUInteger)index {
    if (index < self.count) {
        return [self hookObjectAtIndex:index];
    }
    return nil;
}
```
