# iOS私有库的创建与使用

#### 一、Cocoapods知识点

##### Cocoapods简单使用

- 生成podfile文件 ` pod init ` podfile文件语法参考[这篇文章](https://www.jianshu.com/p/8af475c4f717)

####  二、私有索引库

- 在github、码云等代码仓库平台创建自己的远程私有索引库,比如创建一个叫JCSpecs的索引库
- 在自己电脑上添加一个名为JCSpecs的本地私有索引库

```shell
pod repo add JCSpecs git@git.oschina.net:jingchi/jcspecs.git
```

此时在 /Users/<用户名>/.cocoapods/repos 这个文件夹下会多出一个JCSpecs文件夹

#### 三、私有库

- 1.创建一个pod私有库的模板库比如`JCPayKit`

```shell
pod lib create JCPayKit
```

此时它会帮我们 从https://github.com/CocoaPods/pod-template.git clone 一个pods 的模板库

- 2.在模板库中加入自己写好的私有库
- 3.在模板Example这个文件夹中，执行 `pod install`安装本地的pod
- 4.编写私有库的podspec描述文件
- 5.修改完podspec文件可能会有语法错误，所以需要本地验证

```shell
#--allow-warnings: 表示在有警告的情况下允许通过
--verbose: 验证打印详细信息
--use-libraries: 当你的库有引用or依赖私有库、静态库请加上这个，否则出现Returned an unsuccessful exit code的报错
#
pod lib lint --allow-warnings --verbose --use-libraries
```

- 6.podspec文件验证通过后，把pod提交到本地:

```shell
git add .
git commit -m "提交代码"
```

- 7.关联远程仓库，提交库到远程

```shell
# git remote add origin <项目仓库地址>
git remote add origin https://gitee.com/jingchi/JCPayKit.git
# 查看当时是否已成功关联
git remote
git push origin master
```

- 8.打标签（tag）

```shell
# 此时 tag 版本要和podspec中一致
git tag -a '0.0.1' -m "第一个tag版本" 
```

- 9.本地tag推送到远程

```shell
# 推送所有的tag到远程
git push --tags
# 推送指定tag到远程
git push origin 0.0.1
```

- 10.私有库和私有索引库关联，本地的Sepc更新到远程仓库

```shell
pod repo push JCSpecs JCPayKit.podspec --allow-warnings
```
