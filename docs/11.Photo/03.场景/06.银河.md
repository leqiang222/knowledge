####器材要求

> 高感不错的相机、大光圈广角镜头、三脚架和云台、快门线或者无线遥控器、额外电池

#### 拍摄条件

- 月明星稀，选择月亮最弱的时候，也就是在初一前后
  - 月相：新月-上弦月-满月-下弦月
    - “上弦月”（农历初八左右）。上弦月左右几天的月光就比较强了，对星空拍摄影响很大。不过月亮也是会升落的，上弦月这几天的月亮会在半夜落下，因此后半夜到黎明前天空中不会有月亮，又是星空拍摄的良机
    - 下弦月：
- 如果要拍同心圆星轨：指南针或者肉眼判断北极星的位置
- 暖光的强光手电筒，用于照亮前景

#### 相机设置

+ 星空500法则：最长曝光时间 = 500 / 全副对应的焦距（半画幅* 1.5）
  * 快门25-30，不能超过30秒， 如果超过30秒繁星就会有拖尾的现象
+ 平均测光(矩阵测光)
+ 白平衡（自动或日光）
+ M档
+ 关闭防抖
+ 关闭长时间曝光降噪 
+ 关闭高ISO降噪
+ 光圈：调到最大，以使更多的光进来
+ ISO：2000-6400
+ 曝光补偿减0.7 
+ RAW格式底片

####拍摄手法

+ 对焦

  + 自动对焦进行合焦，合上焦后手动对焦。各家镜头的无穷远标记一般和实际的无穷远有一定的偏差，所以推荐使用背屏寻找亮星来手动对焦。方法是打开相机背屏的实时显示，==放大后寻找一颗比较亮的星星==（或者远处的灯光、月亮），手动转动调焦环，当星星从一个模糊的小圆，变成一个很实的星点的时候就对焦成功。

    但是要注意,在一开始转动对焦环时要把对焦环转动到无限远附近,要不然星星可能直接会被虚化得看不到。

  + 常见参数组合：16mm 30秒 f2.8 ISO3200

#### **月亮拍摄**

##### **相机基础设置**

- 手动M挡、关闭光学防抖、调整手动对焦，可选择开启反光板预升（减少快门震动带来的影响）。

##### 曝光

- 满月固定的参数：ISO 200、F5.6-F8、1/500s。
  - F5.6到F8的光圈是根据你所在的空气情况而定的。自己按照这个参数试试，可以上下调节一下。
  - 为了保证月亮不会糊掉，在没有赤道仪的帮助下曝光时间不建议长于300/镜头焦距 s，例如200mm镜头不建议曝光时间长于1.5s。

- 弦月固定的参数：ISO 200、F5.6-F8、1/125s。
- 红月亮：ISO 800、F5.6-F8、1s。
