### SpringMVC

- 表单：@RequestParam
  + 入参名字与方法名参数名不一致时使用
  + 如：
  ```java
  public String itemEdit(@RequestParam(value="id",required=true,defaultValue="1")Integer ids){
  	// value:传入的参数名，required：是否必填,defaultValue:默认值
  }
  ```

- restful风格：@PathVariable

  - 入参名字与方法名参数名不一致时使用

  - 如：

    ```java
    @RequestMapping("/item/{id}")
    public String testRest(@PathVariable("id") Integer ids, Model model) {
        //restful风格url上的参数通过{}点位符绑定
        //点位符参数名与方法参数名不一致时，通过@PathVariable绑定
    }
    ```


### 路径

- @RequestMapping
  -  可以加在类头部，用于目录分级管理；当然也可以加在方法上面
  - 路径映射可以是数组
    - 如： `@RequestMapping(value = {"test01", "test02"})`
  - 限定请求方法
    - 如：`@RequestMapping(value = {"test01", "test02"}, method = RequestMethod.POST)`
